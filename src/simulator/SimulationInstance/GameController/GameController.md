# GameController

## 模块职责

`GameController` 将用户或业务产生的游戏操作整理为输入，并写入模拟实例的游戏输入通道。

1. 维护输入通道的写入能力。
2. 发布连续控制快照与离散游戏命令。
3. 为输入附加实例所需的逻辑时序信息。
4. 在游戏世界暂停或停止时按照实例约定处理新输入。

游戏控制器只负责游戏输入。启动、暂停、恢复和停止由模拟实例中的生命周期管理模块处理。实例创建时游戏系统已装载。

## 理想结构

```typescript
interface GameController {
  /**
   * 发布一份游戏输入。
   *
   * @param input 游戏输入快照或离散命令
   */
  submit(input: GameInput): void;

  /**
   * 关闭输入通道。
   *
   * @returns 输入资源关闭完成的 Promise
   */
  dispose(): Promise<void>;
}
```

## 关键设计决策

### 1. 输入是实例能力的一部分

控制器写入模拟实例提供的输入通道；游戏系统宿主连接该通道并向游戏系统提供读取端。宿主在同线程和跨线程模式下都存在，通道可由普通内存对象、共享内存或消息传输实现。
