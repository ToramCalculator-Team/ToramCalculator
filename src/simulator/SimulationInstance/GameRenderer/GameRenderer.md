# GameRenderer

## 模块职责

`GameRenderer` 消费游戏系统宿主创建的观察输出，将状态、事件和调试数据转换为界面需要的呈现内容。

1. 接收模拟实例或上层界面取得的观察句柄。
2. 直接读取对应数据通道。
3. 根据最新逻辑状态刷新画面。
4. 关闭时释放读取订阅和呈现资源。

观察者的创建、采样和输出通道由 `GameSystemHost` 管理。渲染器不拥有游戏规则和游戏逻辑时钟；界面使用平台真实时间安排绘制，并在游戏世界暂停时保持最后一帧或呈现暂停状态。

## 理想结构

```typescript
interface GameRenderer {
  /**
   * 读取并呈现一个观察者的数据通道。
   *
   * @param observer 消费端取得的观察者句柄
   * @returns 停止读取和呈现的清理函数
   */
  consume(observer: ObserverHandle): () => void;

  /**
   * 释放渲染器资源和读取订阅。
   *
   * @returns 资源释放完成的 Promise
   */
  dispose(): Promise<void>;
}
```

## 关键设计决策

### 1. 渲染器消费输出句柄

面板打开时由模拟实例向宿主申请观察者；渲染器取得读取句柄后直接读取，不创建采样器或输出通道。
