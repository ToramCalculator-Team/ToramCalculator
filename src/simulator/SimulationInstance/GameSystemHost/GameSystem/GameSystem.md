# GameSystem

## 模块职责

`GameSystem` 是由 `GameSystemHost` 持有并驱动的游戏规则系统。它维护游戏世界状态，读取输入，并按照宿主逻辑时钟完成工作。

1. 接收场景或既有状态作为初始状态。
2. 按输入和逻辑时间推进游戏规则。
3. 在每项逻辑工作完成后更新统一状态对象。
4. 报告当前逻辑时刻与下一项逻辑工作。
5. 向宿主提供状态发布和观察接入所需的读取面。

## 理想结构

```typescript
interface GameSystem {
  /** 逻辑工作完成后的统一状态对象。 */
  readonly state: GameState;

  /**
   * 获取当前已完成的逻辑时刻。
   *
   * @returns 当前逻辑时刻
   */
  getCurrentTime(): GameTime;

  /**
   * 获取下一项逻辑工作的时刻。
   *
   * @returns 下一项工作时刻；没有工作时返回 null
   */
  getNextTime(): GameTime | null;
}
```

## 关键设计决策

### 1. 状态由游戏系统维护

游戏系统负责状态的语义和更新时机。宿主持有游戏系统，提供运行环境并管理观察者；消费端通过观察声明取得投影。

### 2. 时间能力由宿主提供

游戏系统不持有平台定时器。所有逻辑时间读取、等待和暂停都经过宿主时钟。宿主在线程模型变化时持续存在。
