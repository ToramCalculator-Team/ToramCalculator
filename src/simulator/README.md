# Simulation System

## 模块职责

模拟系统管理可独立运行的模拟实例，为业务流程提供游戏运行控制、输入和观察输出能力。

```text
SimulationService
└─ SimulationInstance
   ├─ LifecycleController
   ├─ GameController
   ├─ GameSystemHost
   │  └─ GameSystem
   └─ GameRenderer
```

## 关键设计决策

### 1. 服务管理实例，实例管理游戏运行

`SimulationService` 创建、登记和销毁多个 `SimulationInstance`。实例创建完成时，游戏系统已经装载；实例公开游戏系统的启动、暂停、恢复和停止操作，并在销毁时释放四个组成模块。

### 2. 四个模块各有明确职责

- 生命周期控制器验证运行状态转换并协调执行端操作。
- 游戏控制器写入游戏输入通道。
- 游戏系统宿主提供逻辑时钟、输入输出接入并管理观察者；宿主持有并驱动游戏系统，游戏系统维护并推进游戏世界状态。
- 游戏渲染器按声明读取观察输出并呈现。

### 3. 游戏世界逻辑时间位于执行端

暂停和恢复作用于游戏系统的逻辑时钟，由始终存在的游戏系统宿主持有和操作；平台真实时间继续用于通信、界面刷新和超时。

### 4. 执行位置不改变实例接口

游戏系统宿主在线程模型变化时持续存在。同线程时，输入输出通道使用普通内存实现；跨线程时，宿主通过共享内存或消息通道接入 I/O。实例对调用方保持统一的运行控制、输入和观察接口。
