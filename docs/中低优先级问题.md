   ## 18. PlayerAttrSchema 静态默认 schema 和运行时生成 schema 重复

  文件：

  engine/core/World/Member/types/Player/PlayerAttrSchema.ts
  1407-1431 <-> 2108-2136
  1495-1530 <-> 2212-2247

  一处是静态默认 PlayerAttrNestedSchema，另一处是 PlayerAttrSchemaGenerator() 返回值。

  重复的是大量：

  - displayName
  - 默认 expression
  - 属性树结构

  但运行时生成版本会根据角色、武器、装备计算动态表达式，例如：

  - 等级
  - 武器类型
  - HP/MP
  - 攻击力
  - 攻速
  - 命中
  - 回避
  - 伤害上下限

  结论：静态 metadata 和动态计算 schema 的职责不同，不能直接合并；但字段名称和基础展示信息存在漂移风险。

  建议：

  - 后续将“字段 metadata”和“运行时 expression”拆开。
  - 静态 schema 作为展示定义，运行时只覆盖 expression。
  - 当前不建议为了减少 jscpd 重复率直接重写整份 Player schema。

  优先级：中。

   ## 20. AgentPropertyReference 的整数和数值解析重复

  文件：

  lib/mistreevous/AgentPropertyReference.ts
  30-46 <-> 56-72

  resolveAgentNonNegativeInteger() 和 resolveAgentNonNegativeNumber() 都重复：

  - 直接数值或 agent property reference
  - resolveAgentProperty
  - 可选 fallback resolver
  - 类型检查
  - 非负检查

  区别是：

  - integer 需要整数判断
  - number 需要有限数判断
  - 错误信息不同

  结论：公共解析过程可以复用。

  建议：

  - 抽取 resolveAgentValue()。
  - 两个函数分别保留自己的验证规则和错误消息。

  优先级：中低。
